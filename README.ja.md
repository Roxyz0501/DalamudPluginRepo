# Roxyz0501 Dalamud Plugin Repository

[English](README.md)

`Roxyz0501`が独自開発・管理するDalamudプラグイン向けの共通カスタムリポジトリです。

## リポジトリURL

Dalamudへ次のURLを追加してください。

`https://raw.githubusercontent.com/Roxyz0501/DalamudPluginRepo/main/repo.json`

## 導入方法

1. `/xlsettings`でDalamud設定を開きます。
2. **Experimental（試験的機能）**タブを開きます。
3. **Custom Plugin Repositories**へ上記URLを追加します。
4. 設定を保存し、`/xlplugins`を開いてプラグイン名を検索します。

## 収録プラグイン

- [Kuzushi Beacon](https://github.com/Roxyz0501/KuzushiBeacon) — PvP中、自分が付与した崩しを線と頭上マーカーで表示。読み取りとローカル描画のみ。公開プレビュー、ゲーム内確認待ち。

- [Bait Beacon](https://github.com/Roxyz0501/BaitBeacon) — GatherBuddy Reborn の保存済み Auto-Gather リストに必要な餌を強調表示します。公開プレビュー。ゲーム内の枠位置は未検証です。
- [Allagan Local](https://github.com/Roxyz0501/AllaganLocal) — 所持品・所持金・販売履歴のローカルサイト。Allagan Toolsが必要、販売履歴にはAllaganMarketも必要です。公開プレビュー。

- [Glamour Saver](https://github.com/Roxyz0501/GlamourSaver)
- [Character Archive](https://github.com/Roxyz0501/CharacterArchive)
- [Aether Current Navigator](https://github.com/Roxyz0501/AetherCurrentUnlocker)
- [BGMPlayer](https://github.com/Roxyz0501/AetherRadio) — プレビュー。ゲーム内音声再生の実機確認は未完了です。

各プラグインのソース、Issues、ライセンス、Releaseは、それぞれ個別のGitHubリポジトリで管理しています。`repo.json`はバージョン固定されたGitHub Release ZIPを参照します。
