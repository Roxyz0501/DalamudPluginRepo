# Roxyz0501 Dalamud Plugin Repository

[日本語](README.ja.md)

This is the shared custom repository for independently developed Dalamud plugins maintained by `Roxyz0501`.

## Repository URL

Add this URL to Dalamud:

`https://raw.githubusercontent.com/Roxyz0501/DalamudPluginRepo/main/repo.json`

## Installation

1. Open Dalamud Settings with `/xlsettings`.
2. Open the **Experimental** tab.
3. Add the URL above under **Custom Plugin Repositories**.
4. Save the settings, open `/xlplugins`, and search for the plugin name.

## Included plugins

- [Glamour Saver](https://github.com/Roxyz0501/GlamourSaver)
- [Character Archive](https://github.com/Roxyz0501/CharacterArchive)
- [Aether Current Navigator](https://github.com/Roxyz0501/AetherCurrentUnlocker)
- [BGMPlayer](https://github.com/Roxyz0501/AetherRadio) — preview; native in-game playback testing is pending.

Each plugin keeps its source, issues, license, and releases in its own GitHub repository. Release ZIPs referenced by `repo.json` are immutable, versioned GitHub Release assets.
